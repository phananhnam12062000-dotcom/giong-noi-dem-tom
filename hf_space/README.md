# 🦐 Smart Shrimp Counter - Đếm Tôm Thông Minh Bằng Giọng Nói

Ứng dụng Web nhận diện giọng nói tiếng Việt rảnh tay qua micro điện thoại và máy tính:
- **Chế độ 1: Cân Trọng Lượng & Giới Tính Mẫu**: Bẫy từ khóa thông minh (Male / Female), tính trọng lượng trung bình và Size tôm (con/kg).
- **Chế độ 2: Đếm Số Lượng Cộng Dồn**: Ánh xạ từ ngữ địa phương ("mười lăm", "ba mươi lăm"), lệnh giọng nói Hoàn tác / Xóa mẻ và Đặt lại về 0.
- **Phản hồi âm thanh AI (TTS)**: Tự động phát âm thanh tiếng Việt đọc lại số liệu qua loa điện thoại.
- **Xuất Báo Cáo Excel**: Xuất file `Bao_Cao_Tom.xlsx` chuẩn thẩm mỹ ngành thủy sản (OpenPyXL).
